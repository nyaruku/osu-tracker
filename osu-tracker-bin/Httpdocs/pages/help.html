Template Syntax

Use {{key}} (Mustache) syntax in .txt templates. For .html overlays, connect via WebSocket - keys become element IDs following the same naming convention. See default.html as a reference.

Each field supports these suffixes:

  • _init_raw Initial value (unformatted)
  • _change_raw Change in value (unformatted)
  • _current_raw Current value (unformatted)
  • _init Initial value (formatted)
  • _change Change in value (formatted)
  • _current Current value (formatted)

Example level

{{level_init}} {{level_change}} {{level_current}} {{level_init_raw}} {{level_change_raw}} {{level_current_raw}}
