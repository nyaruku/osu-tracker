Each tracker field can be used in your .txt templates via {{key}} (mustache) syntax,
while .html templates connect through websocket and keys are html classes, they still follow the same naming conventions,
see default.html for more context or as an example, if you want to create your own OBS Overlay. (Would be also nice to PR, if you want to add it for the next release).
You can also use the following variants for dynamic content:

  • _init_raw: Initial value (unformatted)
  • _change_raw: Change in value (unformatted)
  • _current_raw: Current raw value
  • _init: Initial formatted value
  • _change: Change in formatted value
  • _current: Current formatted value

Example: For the field Level with key level:

  • {{level_init}} -> Initial formatted level
  • {{level_change}} -> Change in level
  • {{level_current}} -> Current formatted level
And similarly for the raw variants, by just appending _raw at the end.
